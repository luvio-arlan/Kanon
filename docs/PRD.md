# KANON — 美股投资逻辑操作系统（PRD v1.1）

> 版本：v1.1（品牌定稿） | 日期：2026-11-23 | 定位：Linear 级美股深度研究与交易纪律驾驶舱 | 形态：桌面优先 Web 应用

## 1. 品牌定稿、视觉标识与产品定位

- **品牌名称**：`KANON`（中文名：**卡农**）
- **英文 Slogan**：`Conviction, composed.` / `Quiet precision for long-term minds.`
- **中文宣传语**：**在噪音里，谱出自己的确定性。**（备选：**给长期主义者的精密标尺。**）
- **产品定位**：面向年轻、有追求的深度美股投资者的 **投资逻辑操作系统（Investment Thesis OS）**——把听来的观点，炼成自己算出来的底气。
- **品牌符号与内涵**：
  - 核心图形：左柱如锚（基本面、安全边际与交易纪律），右弧顺势破出向上（复利曲线与超额收益），两笔勾勒出极具张力的现代雕塑感 `K`。
  - 语义双关：既呼应 _Canon_（第一性原理与准则），又呼应音乐中的 _卡农_（层层递进的复调与产业链交叉印证）。
  - 视觉气质：年轻、有追求、有质感、简洁中有内涵——融合苹果原色钛金属（Natural Titanium）的工业克制与现代高定美学，彻底告别廉价金融软件味。
  - 品牌资产存放路径：`assets/brand/`。

### 核心边界（Non-Goals — 坚决不做什么）

1. 不做实时盯盘 K 线终端或券商下单通道（避免制造交易焦虑）。
2. 不做「直接给买卖建议」的算命聊天框（消除认知外包）。
3. 不做多邻国式打卡徽章游戏化（避免制造「刷完关就懂了」的虚假安全感）。
4. 不做社交喊单社区（保持独立思考的安静空间）。
5. MVP 阶段不上 App Store / Google Play（深度研究属于重阅读与写作场景，先做极致桌面 Web 端，跑通后再考虑轻量移动提醒端）。

## 2. 目标用户与核心闭环

先服务创始人自己，帮自己真正看懂公司、建立赔率锚点并赚到钱，再考虑产品化推广：

- **核心用户 A（深度研究与实盘决策者）**：懂部分行业或听过资深大 V 课程，但面对新标的缺乏系统化研究脚手架，容易受股价波动或杠杆诱惑（如过往 7709 杠杆教训）影响决策。
- **核心用户 B（入门学习与内容创作者）**：需要通过经典公司模板快速掌握美股分析框架，并能把研究沉淀一键转化为高质量视频口播稿与知识资产。

**核心业务闭环**：
`新建标的 → 商业模式一票否决 → 拆解 3 个可证伪核心假设 → 一阶资料交叉验证 → 自主算清 3 情景估值赔率表 → 交易前纪律检查单 → 季度复盘与一键导出（Google Drive / 口播大纲）`

## 3. MVP 核心功能与页面规格（4 大模块 + 全局 ⌘K）

交互准则对标 Linear：**键盘优先（Keyboard-first）、零等待乐观更新（Optimistic UI）、结构化块编辑替代空白聊天框**。

### 3.1 全局驾驶舱（Workspace Bento Dashboard）

- 采用 Swiss Bento 卡片网格布局，每只跟踪标的为一张独立卡片：
  - 顶部左：公司全称 + 单行等宽大写赛道微标签（如 `AI SEMICONDUCTOR`）；顶部右：两位数索引编号（`01`、`02`）与 Ticker（`MU`）。
  - 中部：3 个核心假设状态指示灯（绿=验证中/强化，黄=待观察，红=证伪预警）+ 极简估值锚点 Sparkline（当前价 vs 自主测算中性目标价）。
  - 底部：上次复盘时间、当前赔率区间标签与快捷进入箭头。
- 全局命令面板（`⌘K` / `cmdk`）：随时呼出，支持「新建标的」「查行业术语」「快速记一条投资纪律」「触发红队挑刺」「一键导出 Google Doc」。

### 3.2 五步引导式研究画布（Guided Research Canvas）

左侧极简 5 步线性进度导航，右侧为结构化填空与块状笔记区（每一步自带顶级买方提问脚手架）：

1. **Step 1 商业模式滤镜**：结构化勾选与简答（收入复购性/水电煤属性、上下游定价权、管理层与股权治理），不通过直接标记为「放弃观察」归档。
2. **Step 2 核心假设拆解**：强制将听来的看多观点拆解为最多 3 条可量化、可证伪的假设（每条必填：假设内容 + 关键观测指标 + 证伪红线）。
3. **Step 3 一阶资料交叉验证**：接入 SEC 10-K/10-Q 与近 4 季电话会纪要，支持添加上下游关联公司（如英伟达 → 台积电 / 海力士 / 美光），将两家公司对同一产业链口径的对比并排呈现。
4. **Step 4 三情景估值赔率表**：内置极简交互式计算器，用户输入悲观/中性/乐观三种情景下的 2–3 年后营收、净利率/EPS 与合理 PE，实时生成目标价与当前赔率比（Upside / Downside Ratio）。
5. **Step 5 交易纪律与复盘卡**：每次建仓/加仓/减仓前强制弹窗核对个人铁律清单（例如「是否使用杠杆？——铁律禁止」「是否超出单票仓位上限？」「写下认错离场条件」），记录当时的情绪状态与价格锚点。

- **内联术语卡片（Inline Glossary Popover）**：页面中任意行业黑话（如 HBM、CoWoS、CapEx、EV/EBITDA）支持悬停/点击弹出轻量释义卡（白话定义 + 该公司财报中的具体含义），不中断阅读心流。

### 3.3 嵌入式 AI 研究副驾驶（非传统聊天框）

AI 仅通过 3 个精准动作按钮嵌入画布节点，严禁输出无来源猜测：

- **`提炼电话会`**：从指定季度 Earnings Call 自动提取管理层核心指引、资本开支口径及与上季度的措辞变化，附原文段落锚点。
- **`红队挑刺（Devil's Advocate）`**：强制切换至苛刻空头分析师视角，针对用户写下的看多逻辑，输出 3 个最具杀伤力的反驳问题与潜在证伪路径。
- **`一键转口播大纲`**：将当前标的的 5 步研究画布提炼为结构化视频口播脚本（钩子 + 商业模式对比 + 核心数据证据 + 风险提示），直接服务内容创作。

### 3.4 外部生态同步（Google Drive 导出）

- 支持通过 OAuth 2.0 一键将任意标的的研究画布导出为排版精良的 Google Doc，或将全仓标的的估值赔率与复盘记录同步至 Google Sheets。

## 5. 顶级简洁技术架构

- **Monorepo**：`Turborepo + pnpm`（`apps/web` + `packages/ui` + `packages/core` + `packages/ai`）
- **前端**：Next.js (App Router) + React 19 + TypeScript (Strict) + Tailwind CSS v4 + TanStack Query + Zustand
- **数据层**：PostgreSQL（Supabase 或 Neon）+ Drizzle ORM + Zod（全链路类型自动推导）
- **金融数据与不烧 Token 架构**：
  - 财报原件（10-K / 10-Q）：免费官方 `SEC EDGAR API`
  - 结构化财务指标与行情：Financial Modeling Prep / Polygon 免费或入门层，落库 Postgres 缓存，绝不让大模型编造数字
  - 模型路由：`Vercel AI SDK`（支持 Gemini / Claude / OpenAI 一键切换与 BYOK），仅在 4 个高价值节点按需触发

## 6. AI-Friendly 代码库与四层机械门禁

详见根目录 `AGENTS.md` 与 `.rules/postmortems.md`：

1. **L1 静态与类型门禁**：`Biome` + `tsc --noEmit`（Strict 模式，零 `any`、零 `console.log`）。
2. **L2 架构与视觉门禁**：`dependency-cruiser` 强锁依赖方向 + 禁止硬编码 Hex 色值与未封装原生 UI 组件。
3. **L3 金融与 AI 安全门禁**：`packages/core` 纯函数估值计算 100% `Vitest` 覆盖 + `packages/ai` 输出强制 `Zod` 校验。
4. **L4 提交与 CI 卡点**：`Lefthook` pre-commit + GitHub Actions PR 门禁，辅以 `.rules/postmortems.md` 错误沉淀飞轮。
